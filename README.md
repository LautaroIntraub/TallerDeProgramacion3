# 📱 Taller de Programación 3 - Challenges Android

Este repositorio contiene los proyectos desarrollados para la materia **Taller de Programación 3**, utilizando **Android Studio**, **Kotlin**, **Jetpack Compose** y **Material 3**.  

---

## 🛠️ Tecnologías utilizadas

- **Kotlin** → Lenguaje principal de desarrollo.  
- **Jetpack Compose** → Framework declarativo de UI para Android.  
- **Material 3 (Material You)** → Estilos y componentes modernos siguiendo las guías de diseño de Google.  
- **Android Studio** → IDE oficial para desarrollo Android.  

---

## 🌿 Organización del repositorio

El repositorio se encuentra dividido en ramas, cada una con un challenge diferente:  

- **master** → Challenge 1  
- **challenge-2** → Challenge 2  

Ambos challenges consisten en la implementación de **pantallas diseñadas en Figma**, aplicando:  

- **Ruteo** entre pantallas.  
- Uso de **componentes reutilizables**.  
- Integración de **fuentes personalizadas**.  
- Estilos y colores definidos en base a **Material Design 3**.
